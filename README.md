# Placement Portal Application – V2

This project is developed as part of MAD-II.

Tech Stack:
- Flask (Backend API)
- VueJS (Frontend)
- SQLite (Database)
- Redis (Caching)
- Celery (Async Jobs)


The application supports three roles:
- Admin
- Company
- Student

Features:
- Role-based authentication
- Placement drive management
- Application tracking
- Celery background jobs
- Redis caching
